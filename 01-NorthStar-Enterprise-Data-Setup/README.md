# NorthStar Retail & Distribution
## Project 1: Enterprise SQL Server Data Environment Setup & Validation

### Project Status
In Progress

## Business Scenario

NorthStar Retail & Distribution Inc. is a fictional Canadian retail and distribution company operating across multiple business areas, including sales, e-commerce, inventory, warehousing, logistics, procurement, customer service, and finance.

The organization requires a reliable enterprise data environment that can support business intelligence reporting and analytics.

## Problem Statement

NorthStar has millions of transactional records across multiple business processes.

Before this data can be used for reliable Power BI reporting, the SQL Server environment must be established and the data must be understood, profiled, validated, and assessed for quality.

Poor-quality or poorly understood data could result in inaccurate KPIs, unreliable reports, poor performance, and incorrect business decisions.

## Project Objective

The objective of this project is to establish and validate a large-scale SQL Server analytical environment that can serve as the foundation for multiple Power BI solutions.

## Project Scope

The environment covers:

- Sales
- Orders
- Customers
- Products
- Inventory
- Warehousing
- Logistics and Shipments
- Suppliers
- Procurement
- Returns
- E-commerce
- Customer Service
- Employees

The complete environment is designed to contain approximately 48 million synthetic records.
